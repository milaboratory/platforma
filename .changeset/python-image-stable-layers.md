Make the dependency layers of autogenerated python images reusable across builds. Each installed
package has a fixed home layer, picked by hashing its path without the version, and a package's
`.dist-info` shares that home. Every split file gets mtime `SOURCE_DATE_EPOCH` (default 0), and
`.pyc` files are compiled hash-based instead of at install time. An unchanged package therefore
produces a byte-identical layer: after a one-package change, the registry and the cluster nodes
reuse every other dependency layer instead of re-uploading and re-pulling the whole install.
Images now use up to 16 dependency layers of at most about 2 GiB each.
