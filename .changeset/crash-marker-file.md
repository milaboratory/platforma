Hand out the file a crash marker was read from. The one record the parent contributes — the reason the child died, and memory at the moment it stopped answering — reached a report only if the consumer spelled the file name itself, which is how the rename to `death-` dropped it. `readCrashMarkers` now returns the path beside each marker, so the name is spelled in one place.
